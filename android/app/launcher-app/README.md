# مشغّل التطبيقات المتعددة

## الإنشاء
1. افتح Android Studio ← New Project ← **No Activity**.
2. Language: Kotlin، Package name: `com.example.multilauncher`، Minimum SDK: API 26.
3. انسخ `MainActivity.kt` إلى `app/src/main/java/com/example/multilauncher/`.
4. استبدل `app/src/main/AndroidManifest.xml` بالملف المرفق.
5. وصّل الهاتف (تفعيل خيارات المطوّر وتصحيح USB) ثم اضغط Run.

## الاستخدام
1. اختر التطبيقات، وحدّد عدد النوافذ لكل تطبيق.
2. لتظهر النوافذ جنبًا إلى جنب، شغّل المشغّل أولًا في **تقسيم الشاشة** (من قائمة التطبيقات الأخيرة ← تقسيم الشاشة)، ثم اضغط «تشغيل».
3. للحصول على نوافذ حرة بترتيب شبكة تلقائي: فعّل من خيارات المطوّر
   «Enable freeform windows» و«Force activities to be resizable»، ثم أعد تشغيل الهاتف.
4. «حفظ مجموعة» و«تحميل مجموعة» لحفظ تشكيلات جاهزة.

## حدود
- عدد النوافذ وترتيبها يحددهما نظام الهاتف، وبعض التطبيقات ترفض النوافذ المتعددة.
- فتح نفس التطبيق أكثر من مرة ينجح فقط إن سمح التطبيق بذلك.
- التطبيقات الإعلامية (مثل يوتيوب) توقف الفيديو في النوافذ غير النشطة.
- لا يعمل على الآيفون.
