# مشغّل التطبيقات المتعددة

المشروع كامل ويُبنى تلقائيًا من GitHub Actions (انظر README الجذر). للبناء المحلي افتح مجلد `launcher-app` في Android Studio ثم Run.

## الاستخدام
1. اختر التطبيقات (يمكنك البحث بالاسم)، واكتب عدد النوافذ لكل تطبيق.
2. لتظهر النوافذ معًا شغّل المشغّل أولًا في **تقسيم الشاشة** (من قائمة التطبيقات الأخيرة ← تقسيم الشاشة)، ثم اضغط «تشغيل».
3. للحصول على نوافذ حرة بترتيب شبكة تلقائي: فعّل من خيارات المطوّر
   «Enable freeform windows» و«Force activities to be resizable»، ثم أعد تشغيل الهاتف.
4. «حفظ مجموعة» و«تحميل مجموعة» لحفظ تشكيلات جاهزة، ويمكن حذفها من نافذة التحميل.

## حدود
- خارج تقسيم الشاشة والنوافذ الحرة يمنع أندرويد التطبيق الذي صار في الخلفية من فتح غيره، فيُفتح تطبيق واحد فقط، ويحذّرك التطبيق قبل التشغيل.
- عدد النوافذ وترتيبها يحددهما نظام الهاتف، وبعض التطبيقات ترفض النوافذ المتعددة.
- فتح نفس التطبيق أكثر من مرة ينجح فقط إن سمح التطبيق بذلك.
- التطبيقات الإعلامية (مثل يوتيوب) توقف الفيديو في النوافذ غير النشطة.
- لا يعمل على الآيفون.
